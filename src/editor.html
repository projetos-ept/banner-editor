O exemplo inclui todos os campos e os quatro tipos de bloco, com a medida, o título e a cor de fundo do projeto aberto.

Do projeto à impressão

  1. Escolha uma medida. O modelo do anexo usa 90 × 120 cm.
  2. Selecione um bloco ou use a lista de camadas. Arraste para mover, use o canto para redimensionar e edite os campos à direita.
  3. Adicione fotos na biblioteca. Ajuste a opacidade da imagem, do bloco ou apenas do preenchimento.
  4. Exporte JSON para editar depois, inclusive em outro computador.
  5. Baixe o HTML independente ou use Imprimir / PDF.

Na impressão, use escala 100%, margens zero, gráficos de fundo ativados e cabeçalhos/rodapés desativados. A gráfica pode solicitar PDF com tamanho e cores específicos. O HTML usa cores RGB, sem conversão CMYK ou sangria automática.

O cabeçalho do PPTX é uma imagem única. Para editar marcas ou ilustrações internas, substitua essa imagem. Textos e seções do banner permanecem editáveis.

Ctrl+Z desfaz · Ctrl+Y refaz · Delete exclui · setas movem · Shift + setas movem mais.

O salvamento automático e a biblioteca são locais a este navegador. O JSON é o backup que você pode levar consigo.
